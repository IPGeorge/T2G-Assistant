For responseType="instruction": message=null and instruction is a valid T2G Instruction or InstructionSequence JSON object.
For responseType="clarification": message is a concise natural-language question and instruction=null.
For responseType="conversation": message is a helpful natural-language answer and instruction=null.

A single instruction has fields: type, state, action, desc, parameters, assets. parameters is an array of {name,type,value}. assets is an array of {desc,type,source}; AssetType Unknown=0, Identifier=1, ScriptFile=2, Script=3, SourceAsset=4, Node=5. Keep source="" for unresolved assets. Use exact action and parameter names shown below.
