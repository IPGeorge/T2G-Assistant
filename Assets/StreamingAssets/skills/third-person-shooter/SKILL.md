# Third-Person Shooter Skill

## Purpose
Guide the creation of a third-person shooting game.

## Workflow
1. Create a game space.
2. Create the player character.
3. Create the ground and lighting.
4. Create a camera and attach it to the player.
5. Create a weapon and attach it to the player.
6. Create target objects.
7. Add player control and shooting components.
8. Configure the target spawning system.

## Rules
- Reuse existing objects when present in Current GameDesc.
- Do not create duplicate player objects.
- Generate valid T2G instructions.
- Use available assets and supported actions.
- Ask for clarification if essential information is missing.
